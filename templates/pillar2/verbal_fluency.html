Scoring Guidelines
✓ Count These:
  • Different species (dog, cat, lion)
  • Breeds if clearly different (poodle, bulldog)
  • Specific animals (Labrador, German Shepherd)
  • Male/female if clearly different (rooster, hen)
  • Baby animals (puppy, kitten - if parent not named)
✗ Don't Count:
  • Repetitions of same animal
  • Non-animals (car, tree, person)
  • Fictional creatures (unicorn, dragon)
  • Generic + specific of same (dog + poodle)
